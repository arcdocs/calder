# Software on Aire and Calder

:::{note}
We are actively working on the modules on Aire and Calder, and adding documentation for each module. We will release the software section gradually. If you have any queries, please contact us. We appreciate your patience while this work is being completed.
:::

:::{note}
Users may, and are encouraged to, install their own software in their home (`~`) directories. If you think software should be installed as a centrally managed module, see [Requesting new software](page:request-software).
:::

We provide centrally managed software on Aire and Calder through the module system. The software available may differ between the two systems.

Software is categorised into five groups:

- [Applications](./applications/start) - Software applications for various tasks
- [Compilers](./compilers/start) - Compilers for a range of programming languages
- [Interpreters](./interpreters/start) - Interpreters for running scripts and programs
- [Libraries](./libraries/start) - Libraries for enhancing functionality and performance
- [Tools](./tools/start) - Useful system utilities and tools

For guidance on finding, loading, and using software modules, see [Modules and Applications](../system/module_system.md).
