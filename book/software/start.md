# Software on HPC

:::{note}
The module system on **Calder** uses a hierarchical structure, which is different from the module system currently used on Aire. We are gradually adding documentation for the software available on Calder to this site.

For instructions on using software modules on Aire, please refer to the [Aire User Documentation](https://arcdocs.leeds.ac.uk/aire/software/start.html).
:::

:::{note}
We are also preparing the upgrade of Aire to Aire 2.0, which will introduce a hierarchical module system. Once the Aire 2.0 upgrade is complete, we will gradually migrate the software documentation for both Aire 2.0 and Calder to this site.

We appreciate your patience while this work is being completed. If you have any queries, please contact us.
:::

:::{note}
Users may, and are encouraged to, install their own software in their home (`~`) directories. If you think software should be installed as a centrally managed module, see [Requesting new software](page:request-software).
:::

We provide centrally managed software on HPC through the module system. The software available may differ between the two systems.

Software is categorised into five groups:

- [Applications](./applications/start) - Software applications for various tasks
<!-- - [Compilers](./compilers/start) - Compilers for a range of programming languages -->
- [Interpreters](./interpreters/start) - Interpreters for running scripts and programs
<!-- - [Libraries](./libraries/start) - Libraries for enhancing functionality and performance -->
- [Tools](./tools/start) - Useful system utilities and tools

For guidance on finding, loading, and using software modules, see [Modules and Applications](../system/module_system.md).
